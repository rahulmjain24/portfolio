# Rahul Jain — Portfolio

Personal portfolio website built with Next.js, TypeScript, and vanilla CSS.

## Tech Stack

- [Next.js 16](https://nextjs.org)
- TypeScript
- Vanilla CSS

## Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.
